# TSIANFAN 英文官网增量开发需求文档（PRD）

> 参照 UEESHOP 建站系统后台功能，结合 TSIANFAN（厦门）工贸有限公司官网现有技术栈与业务现状制定的增量需求。

---

## 1. 项目信息

| 项目         | 内容                                                                              |
| ---------- | ------------------------------------------------------------------------------- |
| **项目名称**   | tsianfan-website-incremental                                                    |
| **技术栈**    | Next.js 14 App Router + TypeScript + Tailwind CSS + shadcn/ui + Prisma + SQLite |
| **现有语言**   | EN / FR / DE / IT / ES（5 语言，i18n 完整实现）                                          |
| **PRD 语言** | 中文                                                                              |
| **原始需求**   | 参考 UEESHOP 建站后台 26 张截图功能，对比现有网站能力，制定增量开发计划                                      |

---

## 2. 产品目标

**本次增量开发的核心目标：** 补齐 B2B 工贸企业官网在内容营销（博客）、SEO 管理、流量分析深度、产品批量管理和后台可视化配置方面的短板，使 TSIANFAN 官网具备与 UEESHOP 同等级别的内容运营和数据分析能力。

## 4. 需求池

### P0：必须实现（6 项）

> 对业务影响最大的核心功能，直接影响内容营销能力和 SEO 效果。

---

#### P0-01 博客/文章管理系统

**功能描述：**  
新增博客文章 CRUD 模块，支持富文本编辑、分类管理、封面图、SEO 元数据（title/description）。前端新增 `/blog` 列表页和 `/blog/[slug]` 详情页，支持多语言。

**技术方案：**

- 新增 Prisma 模型 `Article`（title, slug, excerpt, content, coverImage, category, status, metaTitle, metaDescription, publishedAt, sortOrder）
- 新增 Prisma 模型 `ArticleCategory`（name, slug, sortOrder）
- Admin 新增 `/admin/blog` 页面，含文章列表 + 编辑器
- 前端新增 `/[locale]/blog` 和 `/[locale]/blog/[slug]` 路由
- sitemap.ts 集成文章页面

**验收标准：**

- [ ] 后台可创建/编辑/删除/发布/取消发布文章
- [ ] 文章支持富文本内容编辑（至少支持基础 HTML：标题/段落/图片/列表/链接）
- [ ] 文章列表显示标题、分类、状态、发布时间、操作按钮
- [ ] 前端 `/blog` 页面可展示文章列表（分页），`/blog/[slug]` 展示文章详情
- [ ] 文章详情页有 SEO 元数据（meta title/description/og tags）
- [ ] 文章页面被 sitemap.xml 收录
- [ ] 文章内容支持多语言（至少 EN 版本必须，其他语言可选）

---

#### P0-02 SEO 管理中心

**功能描述：**  
新建 Admin SEO 管理页面，包含：全局 SEO 设置（全站 title 模板/keywords/description）、关键词管理（关键词 + 对应页面 URL + 目标排名）、站内 SEO 检查清单（各页面的 title/描述/H标签/图片alt 检查状态）。

**技术方案：**

- 新增 Prisma 模型 `SEOKeyword`（keyword, targetUrl, currentRank, lastCheckedAt, sortOrder）
- 新增 Prisma 模型 `SEOChecklist`（pageUrl, hasTitle, hasDescription, hasH1, hasAltTags, score, checkedAt）
- SiteSetting 新增 `globalMetaTitle`、`globalMetaKeywords`、`globalMetaDescription` 字段
- Admin 新增 `/admin/seo` 页面，含 3 个 Tab：全局设置 / 关键词管理 / 检查清单
- 关键词追踪：定时任务或手动触发，记录关键词排名变化

**验收标准：**

- [ ] 全局 SEO 设置可保存全站 title 模板、keywords、description
- [ ] 关键词管理可增删改查关键词列表，记录对应页面 URL
- [ ] 关键词列表显示关键词、目标页面、当前排名（手动输入或API获取）、最后检查时间
- [ ] SEO 检查清单展示各主要页面的 title/描述/H1/图片alt 检查状态（✅/❌）
- [ ] 全局 SEO 设置保存后在前端页面 `<head>` 中生效

---

#### P0-03 Dashboard 流量分析增强

**功能描述：**  
增强现有 Dashboard，新增：流量来源分布（搜索引擎/社交/直接/引荐）、访问终端分布（PC/移动端）、最近 5 条询盘概览、时间范围切换（今天/昨天/7天/30天）。

**技术方案：**

- TrackingEvent 模型新增字段：`referrer` (String?)、`deviceType` (String?)、`sourceCategory` (String?)
- 前端 tracking 脚本增强：采集 document.referrer、navigator.userAgent 解析设备类型
- trackingService 新增 `getTrafficSources()`、`getDeviceDistribution()` 方法
- Dashboard 新增流量来源饼图、设备分布图、最近询盘卡片
- Dashboard 新增时间范围切换器（今天/昨天/7天/30天）

**验收标准：**

- [ ] Dashboard 可按"今天/昨天/过去7天/过去30天"切换统计范围
- [ ] 展示流量来源分布（搜索引擎/社交平台/直接输入/其他），带占比百分比
- [ ] 展示 PC 端 vs 移动端访问占比
- [ ] Dashboard 展示最近 5 条询盘（邮箱、类型、标题、时间）
- [ ] 流量来源数据通过 referrer 解析自动归类，无需手动标注

#### P0-04 产品批量上传

**功能描述：**  
支持通过 Excel/CSV 文件批量导入产品数据，包括 SKU、名称、系列、规格参数等字段。提供下载模板功能。

**技术方案：**

- Admin 新增 `/admin/products/import` 页面
- 后端 API `/api/admin/products/import` 接收文件，解析 CSV/Excel
- 提供 CSV 模板下载（含字段说明：sku, name, series, standSize, panelSize, panelThickness, weight, material, features, isFeatured, isPublished）
- 导入前预览数据，确认后批量写入
- 导入结果报告（成功数/失败数/失败原因）

**验收标准：**

- [ ] 后台可下载 CSV 导入模板（含字段说明注释行）
- [ ] 可上传 CSV 文件，系统解析后展示预览表格
- [ ] 预览确认后批量写入数据库，已存在的 SKU 跳过或更新（用户可选）
- [ ] 导入完成后显示成功/失败统计和失败详情
- [ ] 导入的产品自动关联到指定 Series（通过 series prefix 匹配）

#### P0-05 询盘表单字段配置

**功能描述：**  
后台可配置询盘表单的字段（启用/禁用、必填/选填），支持自定义字段。当前表单字段写死在前端代码中，需要改为动态配置。

**技术方案：**

- 新增 Prisma 模型 `InquiryFormField`（fieldName, fieldLabel, fieldType, isRequired, isActive, sortOrder, options）
- Admin Settings 新增"询盘设置"Tab
- 前端询盘表单组件从 API 获取字段配置动态渲染
- 默认字段：customerName, email, phone, company, country, message, quantity（基于现有 Inquiry 模型）

**验收标准：**

- [x] 后台可查看/启用/禁用/排序询盘表单字段
- [ ] 可设置每个字段的标签、是否必填、字段类型（文本/数字/下拉/文本域）
- [ ] 前端询盘表单根据配置动态渲染
- [x] 提交的询盘数据正确写入 Inquiry 表
- [x] 配置变更后前端表单实时生效（无需重新部署）

#### P0-06 Logo / Favicon / 版权信息后台管理

**功能描述：**  
将网站 Logo、Favicon、版权信息等从代码/环境变量配置迁移到后台可视化管理，支持图片上传。

**技术方案：**

- 前端 Layout 组件从 SiteSetting 读取 Logo/Favicon 路径
- 版权信息在 Footer 组件动态渲染

**验收标准：**

- [ ] 后台可上传网站 Logo（PNG/SVG），上传后前端 Header 立即更新
- [x] 后台可上传 Favicon，前端 `<link rel="icon">` 生效
- [ ] 后台可编辑页脚版权信息文本
- [ ] Logo/Favicon 文件存储在 `/public/uploads/` 目录
- [x] 所有配置变更无需重新部署即可生效

## 6. 待确认问题

1. **博客内容来源**：博客文章由谁撰写？是否需要集成 AI 辅助写作功能（如基于产品规格自动生成 SEO 文章）？
2. **关键词排名追踪方式**：关键词排名数据是通过手动录入还是接入第三方 API（如 Google Search Console API）自动获取？如果接 API，是否有 Google Search Console 账号？
3. **产品批量导入格式**：导入文件优先使用 CSV 还是 Excel（.xlsx）？现有 172 个产品是否有结构化数据源可供首次导入？
4. **多语言博客策略**：博客文章是否需要 5 语言全部翻译？还是仅英文版本即可？如需多语言，翻译流程是手动还是 AI 自动？
5. **水印需求确认**：产品图片水印是否确实有防盗图需求？部分 B2B 平台可能要求无水印原图，是否需要保留原图版本？
6. **301 重定向场景**：是否有已知的 URL 迁移需求（如旧版网站 URL → 新版 URL）？还是仅为未来预防性功能？
7. **会员系统必要性**：B2B 官网的前端会员系统的实际使用场景是什么？是否真的需要客户注册登录，还是询盘表单 + 邮件跟进已足够？
8. **图表库选型偏好**：是否有图表库偏好（Recharts / Chart.js / 纯 SVG）？需要考虑 Next.js SSR 兼容性和包体积。
9. **SQLite 性能瓶颈**：当前使用 SQLite，TrackingEvent 表数据量增长后查询性能如何？是否需要在本次增量中迁移到 PostgreSQL？
10. **Google Analytics vs 自建统计**：如果接入 GA4，是否仍需要维护自建 TrackingEvent 统计？两者定位如何区分？

## 8. 不纳入本期范围的功能

以下 UEESHOP 功能经评估后不纳入本期增量，原因如下：

| 功能             | 排除原因                         |

| 响应式开关          | 网站已全站响应式实现，无需开关              |
